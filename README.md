# «Не такие метели» — филейное вязание

Мобильное веб-приложение с точной схемой 114 × 60 клеток (6840 клеток) и надписью «Не такие метели в ебало летели».

## Возможности
- Большие клетки и подсказка, что провязать сейчас
- Следующий ряд автоматически меняет направление (нечётные: справа налево; чётные: слева направо)
- Прокручиваемая схема со своей подсветкой и режимом работы по участкам
- Переход к любому ряду и клетке; возврат на предыдущую
- Автосохранение на телефоне в localStorage, резервный экспорт/импорт JSON
- Режим офлайн после первой загрузки с помощью service worker

## Публикация
В GitHub откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, **main**, **/(root)** и нажмите **Save**. После публикации адрес будет иметь вид https://tanyafp.github.io/meteli-knitting/ (проверяйте реальную доступность перед использованием).

Для добавления на iPhone откройте опубликованный сайт в **Safari** → Поделиться → На экран «Домой» → Добавить. Начинайте вязание и ведение прогресса уже внутри иконки приложения: iOS может разделять хранилище Safari и установленного сайта. Прогресс не синхронизируется с другими устройствами. Рекомендуется регулярно экспортировать резервную копию.

Для проверки плотности и исходной цепочки свяжите образец. Ориентировочно 347 в.п. для варианта с 114 клетками, но метод начальной цепочки зависит от выбранного начала и техники вязания.

Исходная сетка включена непосредственно в HTML-файл; внешние серверы для работы не требуются.
